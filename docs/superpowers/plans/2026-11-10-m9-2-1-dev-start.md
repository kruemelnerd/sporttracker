## Global Constraints

- Local development starts only with `./dev.sh`.
- Health endpoint: `http://127.0.0.1:8080/api/health`; maximum wait: 60 seconds.
- Garmin key is loaded only when enabled, existing environment key wins, and the key reaches only the backend.
- PostgreSQL remains running when the launcher exits; Ctrl+C and SIGTERM stop backend and frontend.
- No real Garmin API calls, production database use/reset, secret output, force-push, reset, or edits to protected `.opencode` files.
- Preserve existing local changes and existing branch/PR; no merge or deployment.

## Review Focus

- Backend process exits between a failed probe and the next poll: fail immediately, clean up, and never start Vite; test with the synthetic early-exit process.
- Health becomes ready at the deadline: accept success without an extra delay; test readiness on the final bounded attempt.
- Backend command fails while descendants remain in its process group: terminate the whole group; assert no background process remains.
- Garmin enabled but key absent: report the missing-key state without printing secret material; test the diagnostic and current required start behavior.
- SIGINT and SIGTERM during startup and after Vite starts: clean backend/frontend groups, never stop PostgreSQL; cover both signals in the shell tests.
