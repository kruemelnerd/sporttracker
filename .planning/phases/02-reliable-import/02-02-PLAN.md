<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → multipart controller | Size, count, filename, and FIT bytes are attacker-controlled even on a local service. |
| Batch coordinator → per-file importer | A failure crossing this boundary must not influence a neighboring file's transaction. |
| Import service → local file root | Decoded identifiers control content-addressed placement and must not expose local paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-04 | Denial of service | multipart/decode pipeline | high | mitigate | Enforce configured file/request/count bounds before decode and use controlled temporary storage. |
| T-02-05 | Tampering | duplicate classifier/concurrent writes | high | mitigate | Use SHA-256, identity/start-time matching, conservative fallback, database uniqueness backstops, and race regression tests. |
| T-02-06 | Tampering | per-file persistence | high | mitigate | Invoke a proxy-visible transaction per file and assert that failing child writes leave no aggregate rows. |
| T-02-07 | Information disclosure | local data store | medium | mitigate | Keep FIT/GPS in PostgreSQL and configured local storage only; expose no data root and add no telemetry/analytics client. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; retain existing audited dependencies only. |
</threat_model>
