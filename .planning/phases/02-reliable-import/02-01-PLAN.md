<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `POST /api/imports` | Untrusted multipart bytes and client-controlled filenames enter the local service. |
| Import service → filesystem/PostgreSQL | Decoded content and calculated identity cross into durable local storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | original-file placement | high | mitigate | Derive a hash-based path below the configured root; never use a submitted name as a path and keep bytes out of PostgreSQL. |
| T-02-02 | Information disclosure | import controller errors/logging | medium | mitigate | Return only stable outcome code/message and avoid raw FIT, GPS, parser detail, and filesystem-path logging. |
| T-02-03 | Repudiation | normalized import aggregate | medium | mitigate | Persist SHA-256/import metadata with the committed Activity aggregate and return an explicit outcome. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; retain existing audited dependencies only. |
</threat_model>
